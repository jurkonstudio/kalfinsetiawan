Boombastis

Alat browser untuk gambar, teks, kata sandi, dan jaringan. Sebagian besar berjalan di perangkat, jadi berkas dan kata sandi tidak pernah diunggah.

Masalah

Banyak situs alat online meminta unggah berkas atau penuh iklan dan lambat, padahal untuk kompres gambar atau buat kata sandi data tidak perlu keluar dari perangkat.

Solusi

Boombastis menjalankan hampir semua alat sepenuhnya di browser. Halaman dibuat oleh skrip Node tanpa dependensi, sehingga header, footer, sitemap, dan service worker selalu konsisten.

Fitur utama

  • Image Compressor, QR Code, Password Generator, Hash, JSON, Base64
  • Pemeriksa IP & DNS lewat API publik (satu-satunya yang online)
  • Katalog alat dari satu berkas data
  • Optimasi SEO: sitemap, hreflang, data terstruktur
  • Dapat dipasang sebagai PWA
