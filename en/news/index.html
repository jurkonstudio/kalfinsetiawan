Problem

Phone news in Indonesian often mixes fact and rumor with no clear marker.

Solution

A static blog that builds its articles automatically with GitHub Actions, with clear rumor labels and its own admin dashboard for writing and scheduling.

Key features

  • Fast static articles with clean URLs
  • Editorial dashboard for admins
  • RSS feed and sitemap
  • Release schedules and spec tables
  • Stands alone, separate from the game
