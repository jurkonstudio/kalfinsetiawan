Problem

Many online-tool sites ask you to upload files, or are slow and full of ads, yet compressing an image or generating a password never needs your data to leave your device.

Solution

Boombastis runs nearly every tool entirely in the browser. Pages are generated by a dependency-free Node script, so header, footer, sitemap and service worker stay consistent.

Key features

  • Image Compressor, QR Code, Password Generator, Hash, JSON, Base64
  • IP & DNS checker using public APIs (the only online tool)
  • Tool catalog generated from a single data file
  • SEO: sitemap, hreflang, structured data
  • Installable as a PWA
